# Quick 261114-su7: swipe commits on leaving the element ("out = done")

**Goal:** Every swipe (song rows, Now Playing cover, Nowbar, drag-to-close sheets) commits once
dragged past its commit distance; only a release back inside cancels. Row swipes fire at release
instead of at the spring's settle frame. Menu-edit drags (TrackMenu edit grid, RowActionsConfig,
chipReorder) are collision-based and stay as they are.

## Tasks
1. `swipeCommit.ts` — add `shouldCommitOnEnd(dx, v, dist, released)`: release = full rule, abandoned
   end (pointercancel / lost capture / blur) = distance only.
2. `swipeAction.ts` — use it on every end path; fire the callback at release (drop pendingCommit);
   non-passive touchmove preventDefault while captured so Android can't take a flick for a scroll.
3. `coverSwipe.ts` — same rule; try/catch setPointerCapture (a throw killed the gesture); window
   pointerup/cancel/move/blur net while captured; touchmove block.
4. `dragClose.ts` — same rule + guarded capture.
5. Tests: flip the u05 "cancel never commits" cases, add inside-release-cancels + fires-before-settle.
