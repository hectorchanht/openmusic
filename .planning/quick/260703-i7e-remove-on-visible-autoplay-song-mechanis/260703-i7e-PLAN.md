<objective>
Remove the "on visible" auto-play/resume mechanism. When a backgrounded or screen-locked tab returns to the foreground, the player currently re-issues `audio.play()` on the current track via `resumeIfStalled()`. Per the user, this causes unintended playback more often than it helps. Remove it so playback only starts from explicit user action (tap) or normal track-end auto-advance.

Purpose: Stop unwanted foreground auto-playback.
Output: `player.svelte.ts` with the foreground-resume path deleted; test suite updated (the two dead describe blocks removed) and green.
</objective>
