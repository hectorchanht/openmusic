# Phase quick-260614-23h Plan 01: Now-Playing Menu Tweaks Summary

uid-gated the Play next / Add to queue rows so they hide on the currently-playing track, and added a desktop `showSaveFilePicker` Save-As branch to the download flow with graceful mobile/unsupported fallback — all in `src/lib/components/TrackMenu.svelte`.

## What Was Built

### Task A — Hide Play next / Add to queue for the current track
Wrapped both queue buttons in a single `{#if track && track.uid !== player.current?.uid}` block (TrackMenu lines ~249-252). They now render only when the menu's track is NOT the currently-playing one. The guard is uid-based, so it's correct everywhere TrackMenu is used (search rows, queue rows, now-playing) rather than page-based. Remix, the comment block, and all other rows untouched. No new imports (`player` already imported, `player.current` is reactive `$state`).

**Commit:** `6aec6a1`

### Task B — Desktop showSaveFilePicker branch in doDownload
Edited `doDownload(resolved: Track)`. Everything through `await blobStore.put(r.uid, blob)` and the `ext` derivation is unchanged. Now:
- The sanitized filename (`${r.artist} - ${r.title}.${ext}` with the existing char-strip) is computed once and shared by both branches.
- Added an ext->mime lookup (mp3→audio/mpeg, flac→audio/flac, m4a→audio/mp4, aac→audio/aac, ogg→audio/ogg, wav→audio/wav; default audio/mpeg).
- Branch: if `'showSaveFilePicker' in window`, await the picker with `{ suggestedName, types: [{ description: 'Audio', accept: { [mime]: ['.' + ext] } }] }`, then `createWritable()` / `write(blob)` / `close()` / `toast.show(t('toast.downloaded'))` and `return`. Wrapped in its own try/catch: `AbortError` (user cancelled) returns silently with no toast and no fallback; any other picker error falls through to the anchor download.
- Else (and on non-AbortError picker failure): the existing anchor-element download runs unchanged.
- The OUTER try/catch (fetch-failure → `window.open(r.audioUrl, '_blank')` + `t('toast.openedAudio')`) remains intact wrapping the whole fetch+save sequence.
- Used the narrow `(window as any)` cast for `showSaveFilePicker` since the Window type doesn't declare it.

**Commit:** `d744f63`
