# Goal

An opt-in setting that renders the currently-playing track's quality tag (FLAC / 320 / …)
on the Now Playing page. Off by default — the tag is chrome some users will not want.

# Context

`Track` already carries the data: `quality` and `qualityLabel` (`sources/types.ts:43-44`),
populated by the adapters at resolve time and already persisted through
`player-persist.ts:68`. It is already rendered in two places:

- `TrackMenu.svelte:429` — song detail sheet: `qualityLabel || quality || t('menu.detailUnknown')`
- `VersionPicker.svelte:58` — per-version label: `qualityLabel || quality || t('versions.unknownQuality')`

Nowhere on Now Playing. Grep for `quality|bitrate|flac|320` in `NowPlaying.svelte` returns
only false positives (`320` transition durations and a `320px` cover width).

The settings store uses a documented 4-touch-point pattern for a playback boolean, which
`autoExpandOnPlay` models exactly: field init (`settings.svelte.ts:178`), `load()` guard
(`:296`), `save()` (`:395`), `resetPlayback()` (`:491`). WR-10: the default literal lives
only in `defaults.ts`.

# Tasks

## T1 — Setting: `showQualityTag`

**Files:** `src/lib/config/defaults.ts`, `src/lib/stores/settings.svelte.ts`

- Add `showQualityTag: false` to `PLAYBACK_DEFAULTS`.
- Wire all four touch points in `settings.svelte.ts`, mirroring `autoExpandOnPlay`
  (including the `typeof === 'boolean'` load guard so a tampered value falls back).

**Verify:** `settings.showQualityTag === false` on a fresh store; `resetPlayback()` restores it.

**Done:** the flag persists across a reload and resets with the playback group.

## T2 — Settings UI + i18n

**Files:** `src/routes/(app)/settings/playback/+page.svelte`, `src/lib/i18n/*.ts` (15 locales)

- Toggle row in the existing "Playback & motion" section, directly under Auto-expand —
  same `.row-toggle` / `.sw` markup and a `.muted` helper paragraph, matching the
  established shape of that section.
- New keys `settings.showQualityTag` + `settings.showQualityTagDesc` in ALL 15 locale
  dictionaries. `en` defines `TranslationKey`, so a missing key is a compile error, and
  `i18n.test.ts` guards key-set parity. DOUBLE QUOTES for every key AND value — a manual
  convention no formatter enforces.

**Verify:** `pnpm test` (i18n parity suite) + `pnpm check` pass; the toggle flips and persists.

## T3 — Render the pill on Now Playing

**File:** `src/lib/components/NowPlaying.svelte`

- Inside `.meta`, after the `{#key player.current?.uid}` block that holds `.title` /
  `.artist` (`:1320-1337`).
- Read `player.current?.qualityLabel || player.current?.quality`; render NOTHING when both
  are null — an unresolved stub, or a source that reports no tier, must not leave an empty
  box. Gate on `settings.showQualityTag`.
- Small muted pill, consistent with the surrounding type. Keep it out of the `{#key}` block
  so it is not remounted by the crossfade — the value arrives asynchronously after
  `ensureTrackDetails`, and a `$derived` read repaints it in place.

**Verify:** live on the dev server — toggle on, play a track, the tag appears; toggle off, it
is gone.

# Out of scope

- Changing how `quality` / `qualityLabel` are produced by the adapters.
- The TrackMenu and VersionPicker renderings — both stay as they are.
