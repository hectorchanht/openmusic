<objective>
Fix the now-playing / carousel CURRENT cover cell often being stuck black by applying the
existing list-row dead-URL self-heal (probe → evict → re-resolve) to `player.resolvedCover`.

Purpose: Every list row heals a dead cover via `use:lazyCover` (quick-260630-ey2), but the
now-playing current cell was deliberately left out (see the comment at NowPlaying.svelte:67).
It reads `player.resolvedCover`, which is seeded FIRST from `track.cover` — a source CDN
thumbnail that frequently expires or is served over `http:` — and `resolveCoverAsync()` only
re-resolves when `resolvedCover` is null (NowPlaying.svelte:2313 `if (!this.resolvedCover)`).
A non-null-but-DEAD URL is therefore never re-resolved, and NowPlaying.svelte:1165 paints it
as a CSS background — a dead URL fails to load and the cell shows its black background = the
reported "black cover".

Output: A `healCover(uid)` player-store method (probe + evict + re-resolve under the `playGen`
guard) invoked from a one-shot `$effect` in NowPlaying keyed on the current uid + effectiveCover.
No new resolver, cache, npm dep, or /api route — reuse `resolveCoverForTrack`, `removeCoverBoth`,
and the existing `playGen` supersedence guard.
</objective>
