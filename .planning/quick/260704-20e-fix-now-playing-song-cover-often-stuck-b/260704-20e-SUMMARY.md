# Quick 260704-20e: Fix now-playing current cover often stuck black — Summary

Applied the existing list-row dead-URL self-heal (probe → evict → re-resolve) to the ONE
now-playing `player.resolvedCover` field via a new `player.healCover(uid)` store method, wired
from a one-shot `$effect` in NowPlaying keyed on the current uid + `effectiveCover`.

## What & Why

The now-playing / carousel CURRENT cover cell was often stuck black. `resolvedCover` is seeded
FIRST from `track.cover` — a source-CDN thumbnail that frequently expires or is served over
`http:` — and `resolveCoverAsync()` only re-resolves when `resolvedCover` is `null`
(`if (!this.resolvedCover)`). A non-null-but-DEAD URL was therefore never re-resolved, and the
current cell paints it as a CSS background — a dead URL fails to load and the cell shows its black
background = the reported "black cover". Every list ROW already self-heals via `use:lazyCover`
(quick-260630-ey2); the current cell was deliberately left out (the old NowPlaying.svelte:67
comment). This closes that gap.

## Tasks

### Task 1 — `player.healCover(uid)` + tests (commit 5e289c0)

Added a public `healCover(uid)` — the missing counterpart to `resolveCoverAsync` — plus a private
`probeCover(url)` helper (the `decoding='async'` / `referrerPolicy='no-referrer'` Image idiom
`preloadNextCover` already uses) and a private `healProbed` one-shot Set.

Flow (mirrors lazyCover's `resolveCoverForRow`):
1. Bail unless `this.current?.uid === uid` (the effect passed the uid it observed; a mismatch = track changed).
2. Bail unless `httpsOnly(resolvedCover)` (a null/gradient is the resolveCoverAsync MISSING path; non-https isn't a probe target).
3. One-shot guard keyed `${uid}|${url}` (added BEFORE probing) — an errored paint can't infinite re-probe (T-20e-02).
4. Snapshot `myGen = this.playGen` + artist/title.
5. Probe with `new Image()` (SSR-guarded). onload → no-op (zero-network fast path).
6. onerror → re-check `myGen !== playGen` (bail if superseded mid-probe), `removeCoverBoth(uid, artist, title)`, then `resolveCoverForTrack(this.current)`.
7. Re-check `myGen !== playGen` AFTER the await (T-20e-03), commit ONLY a SOLID https result (`this.resolvedCover = url; bumpCoverVersion()`), else keep the gradient (D-12).
8. Whole body wrapped never-throw.

`healProbed` is cleared at `play()` entry (a new track invalidates prior heals + caps growth).
Imported `removeCoverBoth` on the existing cover-version.svelte import line.

Tests: +8 healCover cases (dead-heal evict+re-resolve, healthy-noop, generation-guard discard,
miss-keeps-gradient, one-shot per uid/url, plus uid-mismatch / null / non-https bails). Added a
controllable `Image` stub (settable onload/onerror, captures src) and a `cover-version.svelte`
mock (`importOriginal` + spied `removeCoverBoth`, mirroring the cover-backfill mock).

### Task 2 — Wire NowPlaying (commit 43be983)

Added a `$effect` near the `effectiveCover` derivation that reads `player.current?.uid` +
`effectiveCover` (reactive deps) and fires `player.healCover(uid)` fire-and-forget. Returns early
when there is no current, when `swappedCover` is present (Last.fm hi-res swap already won — verified
real by `maybeSwapCover`'s onload; swappedCover-wins invariant preserved), or when `effectiveCover`
is null (true miss → gradient). The store's one-shot + gen guards make re-runs on re-render safe.
Updated the line-67 comment to note the current cell now self-heals while staying off the
neighbors-only `resolvedCovers` map. The current-cell paint (line ~1165) is unchanged.
