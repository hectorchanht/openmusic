## Task 1: `--color-focus` token (light-theme focus contrast)

**Problem.** Focus indicators use `var(--color-primary)`. In the light theme, Tiffany `#0abab5` is 2.26:1 against `#f7f7fa` and 2.05:1 against `#ececf2`, below the 3:1 non-text minimum (WCAG 1.4.11). Dark theme is fine (6.9:1).

**Action.**
- `src/lib/services/color.ts`: add a pure exported `focusColor(primary: string, surfaces: string[]): string`. Return `primary` when its `contrastRatio` against every surface is at least 3. Otherwise darken (light surfaces) or lighten (dark surfaces) in small steps using the existing helpers until every surface clears 3:1. Fallback: `--color-text`-like `#1a1a22` / `#f4f4f6`. Add co-located vitest cases: tiffany on dark stays tiffany; tiffany on the light surfaces returns a colour ≥3:1 against both; gold/sakura primaries on their dark themes.
- `src/app.css`: add `--color-focus: var(--color-primary)` default in `:root`.
- `src/lib/stores/settings.svelte.ts` `applyTheme()`: set `--color-focus` from `focusColor(primary, [bg, surface-2])` using the active theme's bg and surface-2 values (read them where `applyTheme` already knows the theme; if the surface values only live in CSS, add a small exported map next to `THEME_PRIMARY` and keep it in sync with app.css, with a comment saying so).
- Replace `var(--color-primary)` with `var(--color-focus)` in focus-indicator rules only (`:focus`, `:focus-visible` outlines / box-shadow rings / focus border-color). Known sites: search `.bar input:focus` and `:focus-visible` (~:1040-1042), TrackMenu `.edit-cell:focus-visible` (~:2466), SupporterSheet `.switch input:focus-visible + .track` (~:393), settings/downloads `.cta`, `.txt`, `.chip`/`.row-toggle`/`.advanced summary` (~:553, :601, :617), settings/account `.field input:focus` (~:417). Grep for any others. Do not change non-focus uses of the primary.
- `DESIGN.md`: under Colors → Primary, add a **Focus** (`--color-focus`) bullet describing the rule, and a Do: "Do draw focus indicators in `var(--color-focus)`, never `--color-primary`."

**Verify.** New unit tests pass; `grep -rn "focus" src | grep "color-primary"` returns nothing in focus rules.
