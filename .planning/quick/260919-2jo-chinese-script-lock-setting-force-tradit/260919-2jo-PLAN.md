## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL query string → tab state | an attacker-supplied `?tab=` reaches component state |
| upstream catalog text → converter → DOM | untrusted source strings pass through a new transform |
| localStorage → settings | a tampered `openmusic:settings:v1` supplies `zhScript` |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-2jo-01 | Tampering | `pickTab` / both tab pages | mitigate | Every param is validated against an explicit `ReadonlySet` before it reaches state — the Library's existing T-23-10 guarantee, now shared. An unknown value falls back, never renders. |
| T-2jo-02 | Tampering | `settings.load()` `zhScript` | mitigate | Parse validates against the three-member union and falls back to `'off'`; a garbage value never reaches `lockScriptSync`'s dispatch. |
| T-2jo-03 | Denial of Service | tongwen dict load | mitigate | Both dicts stay behind memoized dynamic `import()` (D-03); `warmScript` is called only when the lock is ON or a content target is zh-Hant, so a non-Chinese user downloads neither. `warmLock` latches once per target — no retry storm. |
