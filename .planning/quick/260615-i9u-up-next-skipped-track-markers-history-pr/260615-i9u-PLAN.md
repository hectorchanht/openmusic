<reactive-set-note>
`import { SvelteSet } from 'svelte/reactivity'`. `SvelteSet` is a drop-in for `Set` — same
`.add()/.delete()/.has()/.clear()/.size` surface — but reads inside a reactive scope (`$derived`,
template) re-run when it mutates. The field stays PRIVATE; expose a thin reactive READ accessor for
the component (a private `$state` Set leaks no cleaner than a getter, and the component must not be
able to mutate the dead-set arbitrarily). Session-only, NEVER persisted (matches today). The test
`beforeEach` `internals.unplayableUids.clear()` keeps working unchanged (SvelteSet has `.clear()`).
