# Quick 260913-je8 — Download in the TrackMenu header, Like as a list row

## Goal

In the long-press TrackMenu sheet: the top-right accent slot becomes **Download**, and the
action list carries **both** Download and Like in text form. Download deliberately appears
twice (header icon + list row) — the user explicitly accepted that duplication.

## Context

Today (D-09) the header cluster is `[Heart] [X]` and the mid-list Like row was removed; the
list already has a tri-state Download row (D-11/D-12). This inverts the header slot and
restores a Like row.

Everything needed already exists — no new services, no new i18n keys, no new CSS:

- `like()` + `liked` derived — TrackMenu.svelte:41,132

- `.mi.accent` (primary tint, reuse for a liked row) and `.hd-btn` / `.hd-btn.liked`
