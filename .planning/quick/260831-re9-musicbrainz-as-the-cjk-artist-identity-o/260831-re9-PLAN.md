# Goal

Act on spike 010. Two user-reported defects plus one identity question:

- 陳奕迅's albums are missing — we show **5**, MusicBrainz has **72**.
- 周杰倫's albums and tracks render in English (`Greatest Works Of Art`) instead of the original
  Chinese (最偉大的作品). No Deezer profile carries the Chinese titles.
- The same artist appears as **three pages** — 周傑倫 / Jay Chou / 周杰倫.

Spike 010 verdict: MusicBrainz answers all three, and the identity merge needs **no heuristic** —
every script variant AND the romanized name resolve to one mbid at score 100.

# Design decisions

- **CJK-gated, not global.** Route to MB only when `detectLang(artist)` (existing, `$lib/i18n/detect`)
  says the name is CJK. Western artists keep today's Deezer path untouched — it works well and this
  change must not regress it. This is the "heuristic merge on cjk queries only" constraint the user
  set, applied at the source-selection level.
- **MB primary, Deezer fallback — not a union (yet).** A union needs cross-source album dedupe;
  start with "MB first, Deezer when MB misses", which fixes both reported defects. Spike 010 flagged
  union as the later upgrade (Deezer carries singles MB omits).
- **No new heuristic merge.** MB's alias graph replaces the CJK-only merge that was on the table,
  which would also have risked pulling "Coldplay Metal Tribute" into Coldplay.
- **Cover misses degrade to the gradient** via layered CSS backgrounds (`url(...), <gradient>`) —
  a 404 image layer simply does not paint and the gradient shows through. No probe call needed.

# Tasks

## T1 — MusicBrainz proxy routes

**Files:** `src/routes/api/musicbrainz/{artist,albums,tracks}/+server.ts` (new),
`src/lib/proxy/musicbrainz-shared.ts` (new)

- `artist?name=` → `{ mbid, name, country, names: { <locale>: <name> } }` (one MB call, `inc=aliases`).
- `albums?mbid=` → `{ albums: [{ id, title, releaseDate, type, cover }] }`. `cover` is the Cover Art
  Archive URL built from the release-group id — no extra call.
- `tracks?rgid=` → `{ tracks: [{ artist, title, position }] }` via `release?release-group=…&inc=recordings`.
- Shared: the required identifying **User-Agent** (MB blocks generic ones), a **503-aware**
  `fetchWithRetry` wrapper with backoff, 24h edge cache on success only, never negative-cache a 503,
  mbid format validation (UUID) before it enters any upstream path.

**Verify:** all three return the spike's measured values for 陳奕迅 and 周杰倫.

## T2 — Client service + locale-aware display name

**Files:** `src/lib/services/musicbrainz.ts` (new)

- `mbArtist(name)`, `mbAlbums(mbid)`, `mbTracks(rgid)` — `cached()` + never-throw, mirroring
  `deezer.ts`'s WR-03 posture exactly.
- `pickLocaleName(names, canonical, artistLang)` — pure, exported, tested. Normalizes MB's
  `zh_Hant` / `zh_Hans_CN` to the app's `zh-Hant` / `zh-Hans`, prefers an exact locale match, then
  the base language, then the canonical name.

**Verify:** unit tests over the real alias payload for 陳奕迅.

## T3 — Artist page: MB albums for CJK artists

**Files:** `src/routes/(app)/artist/[name]/+page.svelte`, `.../albums/+page.svelte`,
`src/lib/services/discography.ts`

- `DiscographyEntry` gains an optional `mbid` (the release-group id) beside `id` (Deezer's).
- Album fetch becomes: CJK name → MB → on miss, Deezer → on miss, Last.fm. Non-CJK keeps today's
  Deezer → Last.fm order.
- `albumHref` carries `mbid` when present so the album page knows to use MB.
- Layered cover backgrounds so a CAA miss reveals the gradient.

**Verify:** 陳奕迅 shelf shows MB's albums with Chinese titles; Coldplay is byte-identical to today.

## T4 — Album page: MB tracklists

**File:** `src/routes/(app)/album/[name]/+page.svelte`

- Precedence: `mbid` → MB tracks; else `dzid` → Deezer tracks; else name → Last.fm (today's path).
- Stub contract unchanged — only the source of the ordered list moves.

**Verify:** 最偉大的作品 lists 最伟大的作品 / 说好不哭 / 不爱我就拉倒 / Mojito …

## T5 — Tests + i18n
