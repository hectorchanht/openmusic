# Quick Task 260711-sm7: Search input clear-X + empty-state recent + delete confirms

## Description

Four search-page UX refinements (`src/routes/(app)/search/+page.svelte`):

1. **Clear (X) icon** inside the search bar that empties the input.
2. **Empty input → recent-only state**: when the input is empty, collapse the
   content area so only the recent-searched keywords list shows.
3. **Per-keyword bin (delete) icon** next to each recent keyword — removes that
   one entry, gated by a confirm.
4. **Clear-all recent** now also gated by a confirm (currently fires instantly).

## Established patterns to reuse (no reinvention)

- **Confirm** = native `confirm(t('key'))` — the app-wide destructive-action idiom
  (`settings/data/+page.svelte`, every settings `resetConfirm`). NOT a custom modal.
- **Sibling tap target** for the bin = mirror the `.row-line`/`.ver` layout already
  in this file (VERSIONS-01) — an independent ≥44px hit area beside the row button,
  never nested inside it.
- **Icons** = per-icon `@lucide/svelte` imports (`X`, `Trash2`) for tree-shaking.
- **Store split** = pure logic in `search-history-logic.ts`, runes wrapper in
  `searchHistory.svelte.ts` (existing convention).
- **i18n** = new keys added to ALL 16 dicts (double-quote convention, `en` reference);
  `t()` supports `{token}` interpolation (`interpolate()` in `i18n/index.ts`).

## Tasks

### Task 1 — Store: per-query removal
**Files:** `src/lib/search/search-history-logic.ts`, `src/lib/stores/searchHistory.svelte.ts`

- Add pure `removeQuery(list, query)` — case-insensitive filter, never mutates `list`

  then `save()`.
- **verify:** `pnpm test` — extend/confirm `searchHistory` tests pass.
- **done:** store exposes `remove()`, pure helper unit-covered.

### Task 2 — Page UI + i18n
**Files:** `src/routes/(app)/search/+page.svelte`, `src/lib/i18n/*.ts` (16)

- Import `X`, `Trash2`.
- Wrap `<input>` in a `.input-wrap` (position:relative) so a `.clear-input` X button
  can sit at the input's right edge; render the X only when `q` is non-empty.
  Give the input right-padding so text never sits under the X.
- `clearSearch()`: `q=''`; cancel typeahead debounce + abort `suggestAc`; abort `ac`/`moreAc`;
  `resetResults()`; `searchSession.reset()` (so a tab-return stays empty, D-02);
  refocus input + `inputFocused=true`.
- `resetResults()`: clear `results`, `variantGroups`, `artistTiles`/`artistTilesFor`,
  `hasMore`, `page=1`, `searched=false`, `someFailed=false`.
- Extend `onSuggestInput()`: when the trimmed input is length 0, call `resetResults()`
  so typing-to-empty also collapses to the recent state.
- Recent-block gate: change from
  `inputFocused && q.trim() === '' && !searched && entries.length > 0`
  → `q.trim() === '' && entries.length > 0` (show recent whenever empty).
- Recent list: restructure each `<li>` into `.recent-line` = keyword button (existing)
  + sibling `.recent-del` bin button (`Trash2`), `aria-label={t('search.removeRecent')}`,
  onclick `removeRecent(entry.query)`.
- `removeRecent(q)`: `if (confirm(t('search.confirmRemoveRecent', { q }))) searchHistory.remove(q)`.
- Clear-all button onclick → `if (confirm(t('search.confirmClearAll'))) searchHistory.clear()`.
- CSS: `.input-wrap`, `.clear-input` (absolute, muted, ≥36px hit), `.recent-line`
  (flex row), `.recent-del` (flex:none, ≥44px grid, muted, hover surface).
- **i18n keys** (add to all 16 dicts after `"search.suggestions"`):
  - `search.clearInput` — aria for the X
  - `search.removeRecent` — aria for the bin
  - `search.confirmRemoveRecent` — `Remove "{q}" from recent searches?`
  - `search.confirmClearAll` — `Clear all recent searches?`
- **verify:** `pnpm check` (typecheck + i18n key-set parity via `i18n.test.ts`); `pnpm test`.
- **done:** X clears input & content; empty shows recent only; bin+clear-all both confirm.
