# Quick 260616-0n6: Default album queues to same-list up-next Summary

Album-originated queues now default their up-next sourcing mode to `'same-list'` so playback continues down the same album instead of falling through to the global genre-`'generated'` default.

## What Changed

- `src/lib/config/defaults.ts` — `UPNEXT_DEFAULTS.perContext` changed from `{}` to `{ album: 'same-list' }`. The existing `Partial<Record<Exclude<QueueContext, null>, UpnextMode>>` type assertion is unchanged and still typechecks. The inline doc comment was updated to describe the album override. `mode: 'generated'` (global default) and the `console.log` were left untouched per the plan.

Because `effectiveUpnextMode('album')` reads `upnextPerContext` (initialized/reset from `DEFAULTS.upnext.perContext`) before falling back to the global `upnextMode`, a fresh load now resolves `'album' → 'same-list'`. All other contexts still resolve to the global `'generated'`.
