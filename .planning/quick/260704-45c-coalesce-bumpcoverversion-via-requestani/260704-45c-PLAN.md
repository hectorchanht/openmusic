<objective>
Coalesce `bumpCoverVersion()` so a burst of cover-land signal bumps within a single animation frame collapses into ONE reactive `_v.n` increment. Optimization backlog item #5.

Purpose: On a cold home visit, `backfillCovers` / `backfillArtistCovers` resolve up to N covers, each firing `bumpCoverVersion()` synchronously → up to N full re-evaluations of every mounted tile's `$derived` cover read across the whole grid. Batching the bump to one-per-frame cuts that fan-out to a single grid re-render per frame. The reactive READS pull the cover URL directly from the cache (getCachedCover*) and call `coverVersion()` only to take the dependency — so a one-frame-deferred bump only defers the repaint (imperceptible), never serves stale/missing data.

Output: A coalescing `bumpCoverVersion()` in `cover-version.svelte.ts` (public API unchanged) + a colocated node-runnable test file.
</objective>
