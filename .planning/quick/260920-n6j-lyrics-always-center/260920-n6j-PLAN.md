<objective>
Keep the active lyric line vertically centred in the visible lyrics band at ALL positions — first and last lines included. Today the browser clamps `scrollTop` to `[0, scrollHeight - clientHeight]`, so the head and tail of the lyric can never reach the anchor. Fix: give `.lyrics` exactly enough blank padding above and below (derived from the actual anchor) that scrollTop 0 puts line 1 on the anchor and max scroll puts the last line on the anchor. Spotify-style — the upgrade path the existing `ponytail:` comment already names.

Purpose: "always centred" was the ask of quick-260919-npfix; this closes the one documented gap it left.
Output: `lyricAnchorMetrics()` pure helper + tests in `lrc.ts`/`lrc.test.ts`; `NpLyrics.svelte` `anchorActiveLine()` wired to it.
</objective>
