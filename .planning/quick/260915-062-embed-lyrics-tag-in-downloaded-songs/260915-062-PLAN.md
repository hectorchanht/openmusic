<objective>
Embed the track's raw LRC (timestamps intact) as the lyrics tag of every downloaded song — the item
Phase 36 explicitly deferred (36-CONTEXT.md "Lyrics embedded as a tag").

this is a zero-fetch addition. Players that parse synced lyrics (Poweramp, foobar2000, Navidrome,
Plex) scroll them in time; players that don't will show `[mm:ss.xx]` literally — the user weighed
and accepted that trade explicitly (LOCKED: raw LRC, no timestamp stripping, no dual plain+synced
mapping).

Output: `AudioTagFields.lyrics` written in the SAME open→set→save pass as every other field, read
back by `readAudioTags`, threaded through the ONE `tagAudioBlob` seam in `download-track.ts`, with
round-trip + seam tests.
</objective>

READ — this is NOT a `firstString` case. Two facts the executor must not rediscover the hard way:
  1. `file.getProperty('LYRICS')` returns `undefined` after save — taglib-wasm routes lyrics through
