# Quick 261102-wl9: app-wide RTL adaptation (/impeccable adapt)

Follow-up to 261102-w2q, which turned `<html dir="rtl">` on for Arabic but only adapted the artist
and album pages. Make the rest of the app read correctly right-to-left.

## Task 1 — logical CSS everywhere
- `text-align: left/right` → `start/end`; `margin-/padding-left/right` → `-inline-start/end`;
  `border-left/right` → `border-inline-start/end` (style blocks only, all .svelte + .css under src).
- Asymmetric positioning that is reading-direction (badges, menu carets, clear button, video
  menu/badge, desktop rail + the Nowbar/NowPlaying insets past it) → `inset-inline-*`.
- KEEP physical: swipe reveal layers (finger direction), cover-swipe strip, scrubber, switch thumbs,
  centred (`left: 50%`) elements, progress fills.

## Task 2 — direction-aware behaviour
- ShelfChevrons: logical sides; RTL scrollLeft (0 → -max) sign-normalised around the pure
  shelf-scroll maths.
- Marquee: keyframe travel uses `--marquee-sign` (+1 under RTL).
- Directional chevrons get `.dir-flip` (SettingRow, settings, home subhead, songs-of-year, shelves).
