<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| share URL `?u=` → `parseEntityParam` → `SOURCES[source].resolve` | attacker-controllable query string decides which adapter is dispatched |
| Android intent URL → `deepLinkPath` → `goto()` | a hostile app can hand the activity ANY VIEW intent URL |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-01 | Tampering | `stubFromUidParam` / `parseEntityParam` | mitigate | closed SourceId-enum regex (D-30 aligned) is the only path to a `source`; no match → null → name resolve (D-10). Tests: unknown source, empty, garbage → null |
| T-38-02 | Spoofing | `deepLinkPath` | mitigate | `https:` + EXACT lowercase host `openmusic.lol`; `new URL` in try/catch; tests reject `evil-openmusic.lol`, `openmusic.lol.evil.com`, `pages.dev`, `http`, `javascript:` |
| T-38-03 | Tampering (open redirect) | `u` carrier | mitigate | the carrier never becomes a URL — it becomes `{source, id}` fed to a registry lookup; `deepLinkPath` returns a same-origin path, never an absolute URL |
| T-38-SC | Tampering | npm installs | accept | no package is installed by this phase (RESEARCH § Package Legitimacy Audit); gate not triggered |
</threat_model>
