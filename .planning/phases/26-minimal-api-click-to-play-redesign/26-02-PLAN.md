<objective>
Keep covers OFF the click-to-play hot path: bind the now-playing / tile art to the source-embedded
cover the resolve already returned (kuwo `pic`, qq `album_pic`, netease `pic`) and only ever run the
expensive Deezer→iTunes→CN chain for genuinely coverless sources (joox/fivesing) or a true miss. Add
a bounded, lazy, post-paint Deezer HQ *upgrade* for the now-playing track (the single optional cover
call in the ~3-call budget).

Purpose: spike 003 measured cover tiers (Deezer+iTunes) and a 7-source CN cover `searchAll` per
coverless tile as a large share of a play's calls; kuwo returns a usable cover inline on 38/38, so
~all plays need zero cover network work. This plan makes that the enforced behavior and proves it.
Output: a Deezer-only HQ upgrade helper, the reworked player cover seam, and a spy test proving the
hot path issues no cover fan-out.
</objective>
