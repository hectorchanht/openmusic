<objective>
Build the LAZY/OPT-IN foundation for Gap 4 (version selector everywhere): a single on-demand
cross-source variant fetch + a VersionPicker that can show a loading state while it runs. This is the
contract the mount plan (26-10) consumes to place the picker in the long-press TrackMenu and the
Up-Next list.

Purpose: a played/queued song carries only its single source, so variant discovery outside the search
page MUST be lazy — a single deliberate cross-source search fired ONLY when the user opens the picker,
never a background fan-out (the UAT's explicit API-cost constraint). This plan owns the fully
independent pieces (a new node-testable service, the picker's loading affordance, and all new i18n
keys) so it can run in parallel with the other wave-1 plans; it touches NO player/similar/NowPlaying
file.
Output: `fetchVariants`, the VersionPicker loading state, and the new i18n keys across all 16 locales.
</objective>
