<objective>
Give the user explicit control over WHICH source version of a song plays. Add a version control before
the play/grip control on a search song row; tapping it opens a mobile-first modal listing every
same-name+artist variant that the search already returned across sources (netease/qq/kuwo/joox/…),
and tapping a variant plays that exact Track.

Purpose: search fan-out already surfaces multiple source rows per song; `dedupeBest` collapses them to
one displayed row (best-quality), discarding the alternates from view. This plan retains those
alternates and exposes them — no new API calls (the data is already in the search result set). It
complements the kuwo-first hot path: the default click stays fast/single-source, and the picker is the
opt-in "give me a different source" escape hatch.
Output: a VersionPicker sheet, an exported variant-grouping helper, the search-row control, and i18n keys.
</objective>
