<objective>
Establish the kuwo-first resolve FLOOR that every other plan in this phase stands on: reorder the
source registry so cross-source failover walks `kuwo → qq → netease → joox → (fivesing → audius →
jamendo)`, and add a SINGLE-SOURCE lazy resolver for sourceless name-only stubs (the shape Plan
26-03's Up-Next produces) so a queued similar-song resolves through ONE source at a time instead of
a 7-source `searchAll` fan-out.

Purpose: kuwo is empirically 100% playable + cover-inline across all 14 language/region×genre
segments (spikes 001/004, POLICY.md), so kuwo-first makes ~all plays resolve in one call and takes
netease off the "dead default primary" hot seat. This is the structural precondition for the ~59→~3
call reduction.
Output: kuwo-first registry order, a name-stub kuwo-first resolver, a bounded (single-source) lyric
fallback, and green typecheck + tests.
</objective>
