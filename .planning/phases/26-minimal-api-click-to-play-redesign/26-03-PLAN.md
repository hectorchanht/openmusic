<objective>
Kill the 56-call flood. Today `buildSimilarQueue` runs `artist.getSimilar` → EIGHT `searchAll`
fan-outs (8 artists × 7 sources = 56 `/api/*` calls, spike 003). Replace it with Last.fm
`track.getSimilar`: ONE call returns exact `{artist,title}` pairs pre-ranked by `match`. Map them to
lazy name-only stub Tracks (Plan 26-01's marker) that resolve on play through the kuwo-first single
source — no re-search. This is the single highest-impact change in the phase (56 → 1).

Purpose: proven by spike 002 (top-5 results verified resolvable in kuwo; Western coverage 4/4, CN
8/10 with an artist-level fallback for the dry case). Combined with Plan 26-01's kuwo-first resolve,
this lands the ~59 → ~3 single-song-play target.
Output: a new edge route mirroring `/api/similar`'s security posture, a rewritten `buildSimilarQueue`,
and a spy test proving a generated-Up-Next play stays at ≤ ~5 `/api/*` calls.
</objective>
