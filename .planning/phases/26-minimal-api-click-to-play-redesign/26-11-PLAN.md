<objective>
Close Phase-26 UAT Gap 6 (MAJOR): picking a version in the picker throws a STUCK JOOX identity-mismatch
error in the nowbar. Root cause: JOOX detail is keyed by a fragile positional `n=jooxIndex`; a picked
mid-list variant's `n` no longer maps to its songmid, so the upstream detail returns a DIFFERENT song,
the cross-field identity guard (joox.ts:~261-272, the known joox-swaps-songmid-songid protection)
correctly refuses the wrong song — but it does so by THROWING, and the throw is not caught on the
click-to-play resolve path (catalog.ts ensureTrackDetails does not wrap the adapter resolve), so it
surfaces as a permanent nowbar error with no fallback/skip.

Two-part fix, contained entirely in joox.ts (+ its test):
- (a) Prefer the STABLE songmid over the fragile n-index. When the n-based detail is NOT identity-
  confirmed (the case that today throws), SELF-HEAL: issue ONE `/api/joox/search?msg=<keyword>`, find the
  item whose songmid/歌曲ID matches the expected identity, read its CURRENT position, re-fetch detail by
  that corrected `n`, and re-validate. If it now confirms, play the CORRECT song (reliable pick).
- (b) On an UNRECOVERABLE mismatch (song absent from the re-search, or the corrected detail still
  disjoint), return the track UNRESOLVED (audioUrl=null, detailsLoaded=false, WITHOUT adopting the wrong
  song's fields) and console.warn the diagnostic — NEVER throw. This routes the failure into player.play's
  EXISTING `!resolved.audioUrl → runFallback → skip` path (the same resolve-fallback/skip mechanism Gap 1
  / plan 26-06 hardens), producing the standard skip notice instead of a stuck error.

Purpose: make a version pick either play the exact chosen song or fail soft (fallback/skip with a
toast), never strand the nowbar. This is a joox.ts-only change — no player/VersionPicker edit — so it
runs in wave 1 with zero file overlap with 26-06/07/08. Wrong-song protection is PRESERVED (the wrong
song is still never adopted; a genuine mismatch just fails soft instead of throwing).
Output: the songmid-located self-heal + graceful never-throw resolve, with updated/added joox tests.
</objective>
