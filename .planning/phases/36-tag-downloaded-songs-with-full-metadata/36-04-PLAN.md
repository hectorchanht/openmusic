<objective>
Deliver opt-in retro-tagging of the app's own existing downloads (D-17/D-18) with per-file failure isolation (D-19), surfaced as a new Settings → Downloads page — the home Phase 34's import button will later share.

Purpose: users who downloaded before this phase have a wall of untitled files. `blobStore.put` is ALREADY the native rewrite path (re-runs `saveToMusic`), so retag needs zero Kotlin and no new plumbing — just a pure sequential loop, a read-back verification before any disk write, and one root-cause fix so a re-put deletes the previous public copy instead of leaving a duplicate.

Output: `retag.ts` + tests, a one-guard fix in `blob-store.ts` `nativePut` + test, the settings page + index row, and 8 i18n keys across all 15 dictionaries.
