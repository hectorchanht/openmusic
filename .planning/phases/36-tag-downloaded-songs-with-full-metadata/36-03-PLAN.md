## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CDN audio response → tagger | Untrusted bytes from qq/kuwo/netease/joox CDNs enter the wasm parser inside the download path |
| Remote cover URL → embedded bytes | `Track.cover` (source-supplied URL) is fetched and its bytes written into the user's file |
| Album URL `?artist=` param → tag | A URL-carried string becomes the `albumArtist` tag value |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-36-07 | Denial of Service | `downloadTrack` on a hostile/huge CDN body | mitigate | `tagAudioBlob` size ceiling + never-reject; result stays `'saved'` with original bytes (D-06); `logAction('download.tag')` surfaces `skipped-size`/`error` in the Activity log |
| T-36-08 | Information Disclosure | Cover fetch used to probe hosts (SSRF-style) | accept | Reuses `resolveArtworkDataUrl` unchanged: https-only direct tier, `/api/og` text-only host-allowlisted tier (T-24-08 control) — no new fetch path (D-13) |
| T-36-09 | Tampering | Path traversal via title → filename | accept | Unchanged: `buildDownloadFilename` sanitize (`/[/\\?%*:|"<>]/g`) still names the file; tagging never touches the filename path (T-29-01-01) |
