<objective>
Wire YouTube Music into the source model as a first-class ANONYMOUS source: add `'ytmusic'` to the
`SourceId` union, create the client adapter (`src/lib/sources/ytmusic.ts`) with a fully-tested
`search()` parse over a real captured InnerTube envelope, and register it LAST in `SOURCES` with an
`autoResolveEligible: false` flag so it is searchable-but-off the kuwo-first resolve/fallback hot path
(mirrors audius/jamendo policy; the kuwo→qq→netease→joox floor is UNCHANGED). `resolve()` here does
only the deterministic own-origin stream-URL stamp (the audius pattern) — the lyrics fetch + resilience
wiring land in Plan 27-04, and the stream/search proxy routes land in 27-02/27-03.

Purpose: this is the foundation every other Plan 27 wave builds on (YT-SRC-01) and it proves the
search parse (YT-SEARCH-01) against captured evidence, per spike 005.
Output: `SourceId`/`SourceAdapter` changes, the adapter, the registry line, a captured search fixture,
and unit tests for the parse + registry placement.

ZERO auth: no account, OAuth, device flow, cookie, or user token is created or referenced anywhere.
</objective>
