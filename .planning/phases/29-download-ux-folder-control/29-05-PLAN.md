<objective>
Move the native public download target from `Music/OpenMusic/` to `Download/openmusic/` — a
COLLECTION change (MediaStore.Audio → MediaStore.Downloads), NOT just a path-string change — and
carry the human filename to the public write. This is DL-FOLDER-01, the phase's one genuinely-new
Android capability and its single highest-risk item.

Purpose: `Download/` is NOT a legal top-level directory for the MediaStore.Audio collection —
writing `RELATIVE_PATH="Download/openmusic/"` into MediaStore.Audio.Media throws
IllegalArgumentException at runtime (29-RESEARCH Pitfall 1, HIGH confidence, supersedes the naive
CONTEXT reading). The fix inserts into MediaStore.Downloads. Unit tests mock the bridge and CANNOT
catch a wrong collection — device UAT is mandatory (29-VALIDATION Manual-Only Verifications).
Output: Kotlin collection swap + saveToDownloads + the blob-store/media-store rename, gated behind a
device-build verification checkpoint.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → public MediaStore (Downloads collection) | native write of a user-visible file |
| filename → RELATIVE_PATH | a crafted name must not escape Download/openmusic/ |
| public-write failure → player | a MediaStore reject must degrade, not crash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-05-01 | Tampering | filename → RELATIVE_PATH | mitigate | filename already stripped of path separators (T-29-01-01) + RELATIVE_PATH is a fixed constant; DISPLAY_NAME cannot add a directory |
| T-29-05-02 | Denial of Service | wrong collection → runtime throw | mitigate | insert into MediaStore.Downloads (Pitfall 1); Kotlin try/catch → reject → blob-store sentinel; app-private copy still landed |
| T-29-05-03 | Denial of Service | large lossless blob | accept | streamCopy chunks 64 KB, no whole-file buffering (WR-02, unchanged) |
| T-29-05-SC | Tampering | npm/pip/cargo installs | accept | No package installs; Kotlin change compiled from the local hand-written plugin (no new dependency) |
</threat_model>
