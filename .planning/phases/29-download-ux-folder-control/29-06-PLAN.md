<objective>
Add the one-shot Settings → Data migration that relocates already-downloaded public files from
`Music/OpenMusic/` to `Download/openmusic/` and rewrites the uid→URI index. This is DL-MIGRATE-01.

Purpose: A cross-collection Audio→Downloads move CANNOT be done by an in-place RELATIVE_PATH update
(29-RESEARCH Pitfall 2) — it MUST be copy-into-Downloads + delete-old-Audio + remap. Per
29-RESEARCH "Alternatives Considered" AND the 29-VALIDATION test map (unit: mock saveToDownloads/
deleteFromMusic/localStorage), this is TS-orchestrated in blob-store.ts reusing the already-tested
`saveToDownloads` (29-05) + `deleteFromMusic` primitives — NOT a new Kotlin method — so it is
node-testable (a Kotlin relocate would be device-only). The copy+delete+remap algorithm, app-private
byte source (D-04), idempotency, and per-uid never-throw from D-15/D-16 are all preserved.
Output: `migrateDownloads` + the native-only Settings button, gated behind a device-UAT checkpoint.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage uid→URI index | migration reads/rewrites a tamperable per-device index |
| app-private copy → Downloads collection | byte source crosses into a new public entry |
| foreign/orphaned MediaStore entries | post-reinstall entries owned by a prior install |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-06-01 | Tampering | uid→URI remap | mitigate | idempotent by URI inspection (isDownloadsUri); a corrupt/partial index re-runs safely; app-private copies never deleted (D-04) |
| T-29-06-02 | Elevation | delete old Audio entry | accept | own entries → no consent needed; a foreign/orphaned entry (post-reinstall) throws RecoverableSecurityException → per-uid catch → skip (never build a consent-dialog flow — out of scope, Pitfall 4) |
| T-29-06-03 | Denial of Service | one uid fails mid-loop | mitigate | per-uid try/catch → skip + continue; resolves {moved,total}, never rejects (DL-RESILIENCE-01) |
| T-29-06-SC | Tampering | npm/pip/cargo installs | accept | No package installs; migration reuses existing native primitives (no new dependency, no new Kotlin) |
</threat_model>
