## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> POST /api/diag | Untrusted headers + body from any client; only the maintainer's device holds a valid upload token |
| Internet -> GET /api/diag[?key=] | Untrusted `Authorization` + `?key=`; only the maintainer's laptop holds the read token |
| Route -> R2 `env.DIAG` | Trusted binding; every write must be preceded by auth + validation |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-33-01 | Spoofing | POST auth | mitigate | `bearerMatches(header, env.DIAG_UPLOAD_TOKEN)` BEFORE the body is read; 401; fail closed when unset. Tests: no-token / wrong-token / no-env |
| T-33-02 | Information Disclosure | any response body | mitigate | Short error codes only; test iterates every response and asserts neither token string appears (parity with T-25c-01) |
| T-33-04 | Denial of Service | oversize / malformed body -> CPU-limit 5xx | mitigate | Content-Length screen -> 512 KiB text re-check -> `screenLogPayload`; store raw text, zero re-serialization; 413/400 not 5xx |
| T-33-05 | Tampering | write on a rejected request | mitigate | `bucket.put` only after step 6; tests assert put NOT called on 401/503/413/400 |
| T-33-07 | Information Disclosure | read via upload token | mitigate | GET checks `DIAG_READ_TOKEN` only; test proves the upload token gets 401 on GET |
| T-33-09 | Tampering | arbitrary `?key=` | mitigate | `isDiagKey` before `bucket.get`; 400; test proves `get` not called |
