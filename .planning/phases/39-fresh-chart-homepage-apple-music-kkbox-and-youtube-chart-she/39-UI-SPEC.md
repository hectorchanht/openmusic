# Phase 39 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase **extends a mature UI**. It adds no new visual language: every new surface is built
from components, selectors and tokens that already ship. Where this spec says "reuse verbatim",
the executor copies the existing snippet or selector and does not restyle it. Mode: `--auto`, so
no user questions were asked. Every choice not locked in 39-CONTEXT.md is logged in
§Discretion Log.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla SvelteKit 5 + CSS custom properties in `src/app.css`; no shadcn, no Tailwind; React-only gate not applicable) |
| Preset | not applicable |
| Component library | none. In-repo components: `CompactRow`, `CompactPager`, `HomeGridPager`, `ShelfChevrons`, `SettingPicker`, `SettingHint`, `PageHeader`, `TrackMenu` |
| Icon library | `@lucide/svelte` (per-icon imports). New icons this phase: `TrendingUp`, `MapPin`, `Archive` (plus the already-imported `Globe`, `ChevronDown`) |
| Font | `'Inter', system-ui, -apple-system, sans-serif` (existing body stack; all sizes in `rem` off a root that `--fs-app` scales. **No px font sizes**, per quick-260920-kxz) |
| Themes | dark (`:root`) + light (`:root[data-theme='light']`), existing tokens only. No per-theme branches |
| Actions reused | `tapBounce` (every new tap target), `longpress`, `dragScroll`, `marquee`, `dragReorder`, `chipReorder` |

## Spacing Scale

Declared values for all **new** CSS in this phase (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between an `.album` tile's cover and its two text lines (matches existing `.album { gap: 4px }`) |
| sm | 8px | Chip gap, skeleton row gap, gap between the chart-region chips |
| md | 12px | Gap between placeholder tiles (= `.albumrow` gap), `.advanced .chips` top margin |
| lg | 16px | Page gutter (existing `(app)` layout `padding: 0 16px`) |
| xl | 24px | Reserved. No new rule needs it (the Classic accordion reuses the existing `.advanced` margin; see exceptions) |
| 2xl | 44px | Minimum touch height for every new heading row, list row and summary row |

Exceptions (inherited verbatim from existing selectors, **not** re-specified by this phase):

existing `.advanced` rules unchanged, so its margin stays `22px 0`.

Touch-target note: `.sw` (40×22) and the density-seg buttons already sit inside rows of 44px or more.
This phase keeps them as they are and does not shrink any existing tap target.

## 1. Home page — new shelves (`src/routes/(app)/+page.svelte`)

### 1.1 Section → shelf map and titles

Seven new section ids join the existing `{#each resolveSectionOrder(...)}` render loop, each rendered
by its own `{#snippet}` and gated the same way as today (`!homeHidden.includes(id) && shelfBudget.per[id] > 0`).

`{region}` is always `regionLabel(cc, settings.appLang)` (see §2.6). For the five main shelves, `cc` is
the resolved Chart region (`resolveChartRegion(saved, appLang)`); for each extra-region shelf it is that
shelf's region.

| Section id | Shelves | Title (en) | Key | Renders when |
|---|---|---|---|---|
| `chart-songs` | 1 | Top songs · {region} | `home.chartSongs` | pool non-empty |
| `new-releases` | 1 | New releases · {region} | `home.newReleases` | region ∈ {hk, tw, sg} **and** pool non-empty. Other regions plan no task: no placeholder, no header |
| `chart-artists` | 1 | Top artists · {region} | `home.chartArtists` | pool non-empty |
| `chart-albums` | 1 | Top albums · {region} | `home.chartAlbums` | pool non-empty |
| `yt-trending` | 1 | Trending on YouTube · {region} | `home.ytTrending` | pool non-empty |
| `genres` | one per selected genre, in the user's chip order | {genre label} (e.g. "Cantopop") | `home.genre.<id>` | that genre's pool non-empty |
| `regions` | one per selected extra region, in the user's chip order | Top songs · {region} | `home.chartSongs` (reused) | that region's pool non-empty |

Genre shelf titles are the localized genre name alone. This mirrors the existing `home.tagShelf: "{tag}"`
shelves. Extra-region shelves use the same title key as the main Top songs shelf, so they read as the
same chart for another place.

### 1.2 Shelf heading: `titleStatic` (new snippet)

The new shelves have **no See-all page** this phase (§Discretion Log), so they must not use `titleNav`:
a chevron and "See all" label that lead nowhere would be a false affordance.

- Markup: `{#snippet titleStatic(label: string)}<h3 class="subhead-static"><span class="subhead-label">{label}</span></h3>{/snippet}`
- CSS: `.subhead-static` shares the `.subhead-nav` box and type rules exactly (width 100%, flex, `min-height: 44px`,
  margin `14px 16px 14px 0`, `padding-right: 6px`, `calc(0.95rem * var(--fs-title, 1))`, weight 700,
  `color: var(--color-text)`). Add it to the same selector list; do not copy the values. It has no chevron,
  no `cursor: pointer` and no hover rule, and it is not focusable.
- `.subhead-label` (existing) gives single-line ellipsis for long titles such as "Trending on YouTube · United Arab Emirates".
- Classic shelves (`top-hits`, `top-artists`, `tags`, `countries`) keep `titleNav` and their `/charts/*` pages unchanged.

### 1.3 Shelf body by density

Density comes from `densityOf(id)`. All shelves of `genres` share `densityOf('genres')`, and all shelves
of `regions` share `densityOf('regions')`, the same way `tags`/`countries` work today.

| Shelf kind | `list` | `pile` | `grid` |
|---|---|---|---|
| **Song** (`chart-songs`, `new-releases`, `yt-trending`, every genre shelf, every region shelf) | `discoveryShelf(items, density)`, reused verbatim | same snippet (`.albumrow` of `.album` tiles + `<ShelfChevrons />`) | same snippet (`HomeGridPager` of `.tile`) |
| **Artist** (`chart-artists`) | body of `topArtistsBlock` verbatim: `CompactRow variant="artist"` | round `.al-cover.round` `.albumrow` + `.al-name.center` + `<ShelfChevrons />` | `artistGridTile(name, cover)` |
| **Album** (`chart-albums`), new `albumShelf(items, density)` snippet | `CompactRow variant="album"` (new variant, below): `title` = album name, `subtitle` = artist | `.album` tile: square `.al-cover` (radius 10px), `.al-name` = album name, `.al-count` = artist, `<ShelfChevrons />` after the row | `.tile` with `.art` + `<img class="al-cover-img">` + `.scrim` + `.label` (`.t-title` = album, `.t-artist` = artist) |

**`CompactRow variant="album"` (new, minimal):** the same layout as `track` (40×40 art, radius 6px,
`.r-title` + `.r-sub` marquee lines). The whole row is **one** `<button>` firing `onopen`. It has no `⋮`
button, no `use:longpress` and no `RowBadges`. It carries `use:tapBounce`. Structurally it matches the
`artist` variant with square art and a subtitle line. No trailing element (parity with the artist variant).

Albums and songs look the same in `pile` and `grid`. The shelf title "Top albums" and the tap behaviour
(opens the album page) are the differentiators, as on YouTube Music and Spotify. No extra badge.

### 1.4 Tile content and covers

- Text goes through the existing display seams: song title and album name use `names.dnTitle(...)`; artist names use `names.dnArtist(...)`.
- Name hygiene (parser-side, so it affects display): KKBOX and YouTube artist names drop their trailing Latin
  alias (`田馥甄 (Hebe)` → `田馥甄`). Apple album names drop ` - EP` / ` - Single`. KKBOX theme-song subtitles
  (` - 電影《…》主題曲`) **stay in the displayed title**; the marquee handles the length.
- Covers: `tileCover(item)` reused unchanged. New items carry embedded art (`image`), rendered as the existing
  lazy `<img class="al-cover-img" loading="lazy" alt="" onerror={hideOnError}>` over a `coverGradient` backdrop.
  Gradient seeds: songs `artist + title`, artists `name`, albums `artist + name`.
- YouTube thumbnails can be 16:9 `i.ytimg.com` frames. The existing `.al-cover-img { object-fit: cover }` crops
  them to the square center. No new rule.

### 1.5 Items per shelf and order

- Each shelf shows `N = clampShelfSize(settings.homeShelfSize)` items **sampled** from its cached pool of up to 50.
  `list` shows `compactCount` (N rounded up to a full column of 4, existing), `grid` shows at most 27 (existing), `pile` shows all N.
- Sampled items render in **chart-rank order** (ascending pool index). The shelf still reads as a chart ("hottest
  first") while its contents vary. No rank numbers are shown, because sampled ranks are non-contiguous.
- The persisted sample survives a reload. Only a cold cache or a Randomize press draws a new one (locked contract).

### 1.6 Taps

| Tile | Tap | Long-press |
|---|---|---|
| Song (all song shelves) | `player.playStub(artist, title, cover, 'home-discovery')`. Toast `home.unplayable` on a miss (existing gate) | existing `tileMenu(item)` (instant stub header + skeleton, then `resolveStub`) |
| Song on `yt-trending` | same, but passes **`null`** as the cover (the tile still *shows* its thumbnail) | same |
| Artist (`chart-artists`) | `goto('/artist/' + encodeURIComponent(name))` | none |
| Album (`chart-albums`) | `goto(albumHref({ name, id: null, mbid: null, image, releaseDate: null, type: 'album' }, artist))` | none |

Every new tap target carries `use:tapBounce`. The `null` cover for trending tiles follows research A12: Google-hosted
thumbnails blank the NowPlaying hero, which paints the cover as a CSS background and has no error event. With
`null`, `play()` runs the normal cover chain. This deviates from the letter of the CONTEXT tap line, so confirm it at plan review.

### 1.7 Loading states

**Placeholder rule (new).** A shelf gets a placeholder when it is *planned* (visible, capable in the
current region, and its fetch is in flight) and **has no cached pool for its exact key**. The placeholder
occupies the shelf's slot in section order:

1. Heading skeleton: a 44px-tall row with the heading margins, holding one `.sk` bar 12px tall and 40% wide.
2. Body skeleton, matched to the shelf's density:
   - `list`: `.compact-skel-pager` with two `compactSkeletonColumn()` (existing snippet, reused verbatim).
   - `pile`: an `.albumrow` of 4 placeholder tiles. Each is an `.al-cover`-sized `.sk` (130px, or 96px under
     `.section.compact`; radius 10px, or 50% for `chart-artists`) above `.cs-bar.cs-bar-title` and `.cs-bar.cs-bar-sub`
     (existing classes), 4px gap.
   - `grid`: 9 `.sk` squares (`aspect-ratio: 1/1`, radius `var(--radius-md)`) in the existing `.grid`.
3. Wrapper `aria-hidden="true"`. The shimmer keeps running under reduce-motion (existing `.sk` exemption).
4. When the task settles with at least 1 item, the real shelf replaces the placeholder **in place**. When it settles
   empty, the placeholder is removed and nothing renders.

The rule covers the cold first load, a **Chart region change** (a region-driven shelf never shows the previous
region's items under the new region's title, so pool keys must be region-qualified, e.g. `chart-songs:tw`), a newly
selected genre or extra region, and un-hiding a new section. The placeholder exists because Top songs depends on
the slowest upstream (Apple, up to 5s). Without it, later shelves land first and Top songs pops in above them, pushing
content down under the user's thumb.

**Global skeleton (existing, condition extended).** The "Top picks" compact skeleton shows only while `loading`,
no shelf of any kind (new, classic, library) has content, **and** no placeholder is rendered. In practice that is a
config with only classic sections visible, during their first fetch.

**Warm load.** Cached pools paint instantly with no skeleton or placeholder.

**Background refresh.** A pool older than about 6h revalidates silently. **Nothing changes on screen.** The fresh
pool is sampled on the next app open or Randomize press (locked).

**Randomize** (existing button, copy unchanged). New shelves re-sample locally and swap tiles instantly, with no
placeholder and no request. The button flips to disabled with `home.loadingPicks` ("Loading…") **only** when a
classic section is visible. That is today's network behaviour, now confined to classic.

**Progressive mount** (existing `REVEAL_INITIAL = 3`, one per frame). A placeholder counts as one shelf in
`shelfCount()`, exactly like the real shelf, so the first 3 slots fill the viewport on a cold load. A section with
no planned task, or one that settled empty, counts 0 (an empty `new-releases` must not use up a reveal frame).
`genres` counts its planned genre shelves; `regions` counts its planned region shelves.

### 1.8 Empty, error and fallback

| Situation | What the user sees | Copy |
|---|---|---|
| One shelf empty (upstream failure, YouTube global-fallback rejected, genre id guard) | Nothing: no header, no gap | none |
| `new-releases` outside hk/tw/sg | Nothing on Home. Settings explains it (§2.2) | `settings.homeSrcUnavailable` |
| Every **visible** section (new + classic + library) empty after settle | Existing D-06 fallback grid (`buildDiversePicks`) | existing |
| Fallback also empty | Existing error line with Retry | `home.noResults` — `common.retry` (existing) |
| Tapped song cannot be resolved | Existing toast | `home.unplayable` (existing) |

No new error copy. The fallback must **not** trigger while any new chart shelf has items (Pitfall 2).

### 1.9 Source attribution

**None on Home.** Headings and tiles do not name Apple Music, KKBOX or YouTube. This matches the existing
Deezer- and Last.fm-backed shelves, which never showed attribution, and keeps 375px headings short. The only
brand on Home is the literal "YouTube" in the Trending title. Attribution lives in the /settings/home row
source lines (§2.2), where it also explains region availability.

## 2. `/settings/home` redesign (`src/routes/(app)/settings/home/+page.svelte`)

### 2.1 Page outline (top to bottom)

1. `PageHeader`, **unchanged** (title `settings.groupHome`, back, trailing **Reset to default** + `confirm(settings.resetConfirm)`).
2. **Sections & order**: one drag list, the true Home render order (§2.2).
3. **Charts**: Chart region, More regions, Genres (§2.3).
4. **Classic (Last.fm / Deezer)**: collapsed accordion holding the four classic sections plus their tag and country chips (§2.4).
5. Existing global controls, **unchanged and in today's order**: Items per shelf, Home grid columns, Default landing tab, Tile density, Home controls.

The two top-level sections that exist today, "Genres" (Last.fm tags, `Tags` icon) and "Countries" (`Globe` icon),
are **removed from the top level** and move into Classic.

### 2.2 Sections & order: one global list

**Layout decision:** a single drag list presented as the Home render order, not per-group reorder lists.
Per-group lists would take away cross-group ordering that users have today (for example, dragging Top songs above
Liked songs). With one global list, what the page shows is exactly what Home renders. Group identity comes from
each row's source line, the Charts section below, and the Classic accordion. The persisted `homeSectionOrder`
stays one array.

- Container: existing `<section>` + `<h2><LayoutGrid size={15} /> {t('settings.homeSections')}</h2>` + `ul.reorder use:dragReorder`.
- **Rows listed:** every section id **except** the four classic ids. By default that is 13 rows, in resolved order:
  Liked songs, Downloads, Your Radio, Top songs, New releases, Top artists, Top albums, Trending on YouTube,
  Genre charts, More regions, Favourite artists, Playlists, Recently played.
- **Row anatomy:** the existing `.rrow` (grip `data-reorder-handle` → text block → `.density-seg` → `.sw`) with one change.
  The label becomes a text block: `<span class="rtext"><span class="rlabel">…</span><span class="rsub">…</span></span>`
  (`.rtext { flex: 1; min-width: 0; display: flex; flex-direction: column; }`, no gap, because the line-height
  provides the spacing). `.rsub` uses the §Typography Label role in `--color-text-muted`.
- **`.rsub` source lines:** brand names are **literal strings in code** (proper nouns, the same rule as the endonyms on
  /settings/translation), joined with `" · "`:

| Row | `.rsub` |
|---|---|
| Top songs | `KKBOX · Apple Music` when the resolved region ∈ {hk, tw, sg}, else `Apple Music` |
| New releases | `KKBOX` when the resolved region ∈ {hk, tw, sg}, else `t('settings.homeSrcUnavailable', { region })` (e.g. "Not available in US") |
| Top artists | `YouTube` |
| Top albums | `Apple Music` |
| Trending on YouTube | `YouTube` |
| Genre charts | `Apple Music · Deezer` |
| More regions | `Apple Music` |
| Liked songs, Downloads, Your Radio, Favourite artists, Playlists, Recently played | `t('settings.homeSrcLibrary')` ("Your library") |

- An unavailable New releases row stays fully toggleable, with no dimming. The setting persists and takes effect if the region changes.
- **Drag semantics:** `onReorder(from, to)` indexes into the *listed* (non-classic) rows. Write back through a new pure
  helper in `home-layout.ts` (node-tested): classic ids **keep their exact array index**, and the listed ids refill the
  remaining indices in the new order. Result: `homeSectionOrder` stays one complete array, and a hidden classic id never moves.
- Help line under the list: existing `settings.dragToReorder`.

### 2.3 Charts group

Container: `<section>` + `<h2><TrendingUp size={15} /> {t('settings.homeGroupCharts')}</h2>`. It contains, in order:

**a. Chart region**: a single-select `<details class="advanced">` row, reusing the /settings/translation accordion row verbatim
(row-type summary, `.cur`, `.chev`):
- Summary: `<MapPin size={15} />` · `t('settings.chartRegion')` · `<SettingHint label={t('settings.chartRegion')} text={t('settings.chartRegionDesc')} />` · `<span class="cur">{current}</span>` · `<span class="chev"><ChevronDown size={15} /></span>`.
- `.cur`: `t('settings.chartRegionAuto', { region })` when saved is `'auto'` (e.g. "Auto (Hong Kong)"), else `regionLabel(saved)`.
- Body: `<div class="chips" role="group" aria-label={t('settings.chartRegion')}>`. The first chip is **Auto** with the same
  `chartRegionAuto` label, showing the region Auto resolves to right now (including any `navigator.language` refinement the
  resolver applies). Then the 27 offered regions in the fixed research order: hk, tw, sg, jp, kr, us, gb, ca, au, de, fr,
  es, it, pt, br, mx, ru, tr, th, vn, id, in, ph, my, sa, ae, eg. The order is geographic and Asia-first, not alphabetical,
  so it stays stable in every UI language.
- Tap sets `homeChartRegion` and calls `save()` immediately. Selected chip = `.chip.on` + `aria-pressed="true"`. The accordion stays open so the change is visible.
- Collapsed by default; open state is not persisted.

**b. More regions**: a multi-select `<details class="advanced">` row with the same summary anatomy:
- Summary: `<Globe size={15} />` · `t('settings.moreRegions')` · `SettingHint` (`settings.moreRegionsDesc`) · `.cur` · `.chev`.
- `.cur`: `t('settings.moreRegionsNone')` when empty, else the selected region labels joined by
  `new Intl.ListFormat(settings.appLang, { type: 'conjunction', style: 'narrow' })`. Verified output: en "Taiwan, Japan, South Korea",
  zh-Hans "台湾、日本、韩国", de "Taiwan, Japan und Südkorea". `.cur` ellipsizes.
- Body: the existing countries-chip idiom, reused. **Selected chips first**, in saved order, draggable via `use:chipReorder`
  (`data-chip-index`), then the **unselected pool**: offered regions minus the main resolved region minus the selected ones,
  in the fixed order. Every chip has `aria-pressed`. Below: `<p class="muted">{t('settings.homeDragReorderChips')}</p>` (existing).
- Default: **none selected**.

**c. Genres**: always visible (11 chips fit in about 3 lines at 375px):
- `<h3 class="sub">{t('settings.homeGenres')}<SettingHint label={t('settings.homeGenres')} text={t('settings.chartGenresDesc')} /></h3>`
  (existing `.sub` rule, existing `homeGenres` key "Genres").
- Chips use the countries-chip idiom: selected first (draggable, saved order = shelf order), then unselected in pool order
  cantopop, mandopop, kpop, jpop, hiphop, rock, dance, rnb, electronic, alternative, asian. Label `t('home.genre.<id>')`. `aria-pressed` on every chip.
- Muted line: `t('settings.chartGenresNone')` when none are selected (an empty selection means **no** genre shelves; there is no
  fall-back-to-all), else `t('settings.homeDragReorderChips')`.
- Default selected: cantopop, mandopop, kpop, jpop, hiphop, rock, dance, rnb (locked).

### 2.4 Classic group (de-emphasised, discoverable)

A `<details class="advanced classic">`, **collapsed by default** (no `open` attribute; open state not persisted), placed after Charts.
- Summary: the Playback group-disclosure type (the existing `.advanced summary` rule from /settings/playback: 0.85rem uppercase,
  0.5px tracking, muted), plus the translation `.cur` and `.chev` parts:
  `<Archive size={15} />` · `t('settings.homeGroupClassic')` · `<SettingHint label={t('settings.homeGroupClassic')} text={t('settings.homeClassicDesc')} />` · `.cur` · `.chev`.
- `.cur`: `t('settings.optOff')` when all four classic sections are hidden, else `t('settings.homeClassicOnCount', { n })`.
  A closed accordion therefore still says whether any old shelf is on.
- Body, in order:
  1. `ul.classic-rows`: four rows in the fixed order Top hits, Top artists, Genre shelves, Country shelves. The existing `.rrow`
     **without the grip** (text block → `.density-seg` → `.sw`). Labels are the existing keys (`settings.homeSectionTopHits`,
     `…TopArtists`, `…Tags`, `…Countries`). `.rsub` is the literal `Deezer`, `Deezer`, `Last.fm`, `Last.fm`. Rows use `--color-bg`
     inside the panel (`.advanced .rrow`, the same step-down as `.advanced .chip`). **Not draggable:** a classic shelf keeps its saved

### 2.5 Unchanged global controls

### 2.6 Label localization

- **Region names** come from `Intl`, not i18n: `regionLabel(cc, lang)` =
  `new Intl.DisplayNames([lang], { type: 'region', style: 'short' }).of(cc.toUpperCase())`, wrapped in try/catch with a
  `cc.toUpperCase()` fallback, and memoized per language. `style: 'short'` gives "Hong Kong" (not "Hong Kong SAR China"), "US", "UK".
  One pure helper, shared by Home titles and settings. Verified: zh-Hant 香港/台灣/美國, ar هونغ كونغ, th ฮ่องกง.
- **Genre names** use i18n keys `home.genre.<id>`, because they need real translation (e.g. Cantopop → 廣東歌 in zh-Hant is a translator call).
- **Brand names** (Apple Music, KKBOX, YouTube, Deezer, Last.fm) are literal strings and never translated. Inside translatable
  strings they stay verbatim.
- **Classic tag and country chips** keep showing their raw Last.fm strings, as today (unchanged).

## 4. Accessibility

- **Chips** (region, more regions, genres, classic tags/countries): real `<button>`s, keyboard-reachable, Enter/Space toggles.
  **Every new chip carries `aria-pressed`.** The Chart region chip set sits in `role="group"` with `aria-label`. Chip drag-reorder
  stays pointer-only (parity with today); order can still be set by toggling chips off and on.
- **Visibility switch `.sw`** (both lists): add `role="switch"` and `aria-checked={!homeHidden.includes(id)}` next to the existing
  `aria-label` (section name). Today's switch exposes no state; this one-attribute fix covers every row.
- **Density segment:** existing `role="group"` + per-button `aria-pressed` + "{section} · {option}" `aria-label`, unchanged.
- **Accordions:** native `<details>/<summary>`, so Enter/Space toggles with no JS. `SettingHint` inside a summary already stops
  propagation (existing). The chevron rotation is `aria-hidden` and gated by `prefers-reduced-motion` (existing rule).
- **Home headings:** new shelf titles are `<h3>` (the page's `h2` is "Top picks"). Placeholders are `aria-hidden="true"`.
  Tile images use `alt=""` because the visible text names the tile.
- **Grip:** existing `aria-label={t('settings.dragToReorder')}`, unchanged.
- **Motion:** no new animation. The skeleton shimmer and marquee keep their existing reduce-motion exemptions. `tapBounce` follows the app's Reduce Motion setting (existing).

## Discretion Log

Choices made under `--auto`, none of them locked by CONTEXT:

| # | Decision | Why |
|---|---|---|
| UI-1 | No See-all pages for new shelves; they get a non-navigating `titleStatic` heading | Research OQ3/A10. A chevron leading nowhere is a false affordance |
| UI-2 | /settings/home = **one global drag list** (non-classic rows) + Charts section + collapsed Classic accordion, instead of three per-group reorder lists | Keeps today's cross-group ordering and 1:1 parity with the Home render order. The persisted order stays one array |
| UI-3 | Classic rows sit in the accordion, not draggable, and keep their saved array index | Keeps legacy shelves out of the way. Ceiling: an enabled classic shelf cannot be moved. Add a grip if users ask |
| UI-4 | Chart region = single-select chips in a collapsed `.advanced` accordion (not a 28-pill `SettingPicker`) | Same idiom /settings/translation uses for long single-select lists (quick-260919-hm2) |
