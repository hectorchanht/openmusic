If ffmpeg is absent, record it and ask the human to supply 4 audio files ≥ 45 s in the checkpoint.
    5. Push: `adb push "<scratch>/Adele - Hello.mp3" /sdcard/Music/`, the flac and m4a and ring.mp3 into `/sdcard/Music/`, and `Download Test - Song.mp3` into `/sdcard/Download/`. Trigger a MediaStore scan: `adb shell content call --uri content://media/external/file --method scan_volume --arg external_primary` (API 30+); if that errors, fall back to `adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE -d file:///sdcard/Music/ring.mp3` per file.
    6. Pre-check independent of the app (this answers half of UAT 2 without any permission): `adb shell content query --uri content://media/external/audio/media --projection _id:_display_name:relative_path:duration` — record the output in the SUMMARY. Both `Music/` and `Download/` rows should be listed by MediaStore itself; if `Download/` rows are missing here, the emulator's scanner did not index them (re-scan) — this is NOT yet the READ_MEDIA_AUDIO question.
    7. Optional CDP: `adb forward tcp:9222 localabstract:chrome_devtools_remote` so the human can open `chrome://inspect` and read `localStorage['openmusic:library:v1']` during the checkpoints.
