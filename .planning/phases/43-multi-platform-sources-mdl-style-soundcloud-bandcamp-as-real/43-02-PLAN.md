<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client query string → edge route | `q`, `id` are untrusted; only ids and a capped `q` cross |
| edge → bandcamp.com / bcbits.com | fixed URL templates; redirect `Location` is untrusted until host-checked |
| bcbits bytes → client (stream route) | own-origin byte pipe; must never become an open proxy |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-04 | Spoofing/SSRF | `/api/bandcamp/stream`, `/resolve` | mitigate | ids only (`/^\d{1,12}-\d{1,12}$/`); upstream URL from template; `isBcbitsMediaUrl` on the 302 Location BEFORE any fetch |
| T-43-05 | Tampering | search row `cover` | mitigate | `safeImageUrl(raw, BANDCAMP_IMAGE_HOSTS)` at parse time; art URL built from numeric `art_id`, never echoed from `img` |
| T-43-06 | DoS (upstream abuse) | search route | mitigate | `cachedUpstreamJson` 1 h own-origin cache; `q` capped at 200 chars; `AbortSignal.timeout(8000)`; 1 retry max |
| T-43-07 | Info disclosure | resolve/stream responses | accept | signed bcbits URL is public-by-design (24 h, no account); no secrets involved |
| T-43-08 | DoS (edge egress) | stream byte-pipe | accept | same posture as ccmixter/bilibili stream routes; download-only leg, playback stays direct |
| T-43-SC | Tampering | npm installs | accept | none in this phase |
</threat_model>
