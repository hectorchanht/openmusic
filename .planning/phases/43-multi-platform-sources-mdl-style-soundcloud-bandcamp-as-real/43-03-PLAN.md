<objective>
SoundCloud edge layer: client_id scraper with cache + 401 rescrape-once, the pure `pickTranscoding`
switch (progressive → hls aac_160k → aac_96k; SNIP/BLOCK/snipped/preview/abr excluded, per D-09),
search + resolve routes. The edge returns `kind` per row/URL because only the browser knows whether
native HLS is playable (plan 07 gates on `canPlayType`).

Purpose: api-v2 is not CORS-open to our origin, so every SoundCloud call is edge-side.
Output: `$lib/proxy/soundcloud.ts` (+ tests, fixture) and two routes.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client query → edge | `q`, `limit`, `id` untrusted |
| edge → soundcloud.com / api-v2 / sndcdn bundles | scraped JS is untrusted text; only a 32-char `[A-Za-z0-9]` literal is extracted |
| transcoding `url` from api-v2 → hop fetch | upstream-supplied URL; host-checked (`*.soundcloud.com`) before fetch |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-09 | SSRF | `scJson` absolute-URL hop | mitigate | hostname must end `.soundcloud.com`; `/tracks/{id}` id regex `/^\d{1,12}$/`; no caller URL param on any route |
| T-43-10 | Tampering | scraped `client_id` | mitigate | strict 32-char regex; cached under an own-origin key (never the upstream URL) |
| T-43-11 | DoS (upstream abuse / DataDome) | scrape + api-v2 | mitigate | memo + Cache API 6 h; rescrape ONCE per 401; ≤ 4 subrequests per resolve; search cached 1 h |
| T-43-12 | Tampering | row `cover` | mitigate | `safeImageUrl(…, SOUNDCLOUD_IMAGE_HOSTS)` |
| T-43-13 | Info disclosure | resolve body | accept | signed media URL is public-by-design (ACAO *, ≤ 2 h), no secrets |
