<objective>
Wire the client to the edge resolve cache: read it first, treat it as advisory, and repair it on failure (D-08/D-09/D-11).

Purpose: D-11 is explicit that a globally-shared audio URL WILL 403 for some other user, so the failure path is the load-bearing part of this feature, not an edge case. It is planned and tested as the primary path.
Output: one never-throw client service, one insertion point in `ensureTrackDetails`, and one line in the player's error handler.

**Scope guards, all locked and non-negotiable.** `RESOLVE_WATCHDOG_MS` stays 6000 (D-01). No hedged or parallel SOURCE racing (D-02) — the kuwo-first serial resolve stands. The cache read is one own-origin lookup with a tight deadline placed serially ahead of one source resolve, which is not the rejected multi-source race. The optimistic now-playing swap is untouched (D-04). Spending one extra own-origin call to make a play feel instant is an accepted trade (D-05).
</objective>
