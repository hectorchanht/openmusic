## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-40-03-01 | Tampering (ZIP slip) | zip entry names | mitigate | `albumFolder` + `buildDownloadFilename` are the only name sources; both route through `sanitizeFilename`/`sanitizePathSegment`; names never contain `..` or a leading `/` |
| T-40-03-02 | DoS (memory on large lossless albums) | web zip assembly | mitigate | entries reference IndexedDB-backed blobs via `blobStore.get`; CRC streamed; Pitfall 6 UAT item in checkpoint |
| T-40-03-03 | DoS (API fetch flood) | album loop | mitigate | sequential loop, no new concurrency; `resolveAllCached` keeps its ≤4 cap; no per-song anchors |
| T-40-03-04 | Repudiation / UX (silent partial failure) | progress toast | mitigate | `Saved X of Y` always reports the real count; failures skipped, never hidden |
| T-40-03-05 | Tampering (duplicate library entries on uid mismatch) | held-single detection | mitigate | `sameSongKey` match + held entry's own uid used for move/get (Pitfall 3) |
| T-40-SC | Tampering | package installs | accept | none in this phase |
</threat_model>
