<objective>
Wire the enrichment into the player. Two pieces: a pure, memoised `local-tags.ts` that turns an offline blob into `{ lrc, art }` (embedded LRC only when `parseLRC` yields lines; art only when MIME-allowlisted and under `MAX_ART_BYTES`; negative results memoised), and the `player.svelte.ts` changes that make the offline-blob branch fall through to the shared post-play tail, run the tag read as the GATE for the network fallbacks, and route a device track's lyric miss through `lyricByName`.

Purpose: The single root cause is the `return;` at the end of `play()`'s offline-blob branch (RESEARCH Summary). Everything the phase wants — cover chain, up-next, lyric backfill that actually works — lives below it. This plan removes that return for ALL offline-served tracks (orchestrator ruling 1, `37-D-01`), not just `device:` uids, so no second code path is created.
Output: `local-tags.ts` + tests, and a `player.svelte.ts` whose blob branch behaves like the network branch from the src-set onward.
</objective>
